# FR-AUT-001: Menu mặc định

| Mục | Nội dung |
| --- | --- |
| Mô tả | Cấu hình menu fallback hiển thị cho khách không có Menu tùy chỉnh hợp lệ.<br>**Phạm vi:** Bao gồm singleton Menu mặc định theo kênh; danh sách item; sắp xếp; preview; lưu nháp; validate; publish/sync; retry sync; resolve fallback; click item và phát `action.requested`. Không bao gồm tạo/xóa menu tùy chỉnh; quan hệ gán menu cho khách (FR-002); editor nội dung; logic action đích; cách tính metric (FR-011).<br>**Dữ liệu sở hữu:** `DefaultMenu {id, tenantId, channelId, draftVersion, publishedVersion?, syncStatus, items[]}`. Mỗi `MenuItem` có `{id, title, order, actionRef}`. `(tenantId, channelId)` là unique key. Giới hạn item/title lấy từ `channelCapabilities`, không hard-code chung cho mọi kênh. |
| Đối tượng liên quan | Admin/Quản lý có quyền; khách hàng; connector kênh. |
| Pre-conditions | Kênh tồn tại; người dùng có quyền; connector khai báo capability menu. |
| Điều kiện kích hoạt | Quản trị mở Automation → Menu mặc định; hoặc resolver cần menu cho khách. |
| Luồng xử lý chính | 1. Hệ thống tải Menu mặc định, trạng thái sync và capability của kênh; nếu chưa có thì khởi tạo singleton rỗng.<br>2. Quản trị thêm/sửa/xóa/kéo thả item. Popup item yêu cầu tiêu đề và một `ActionRef` hợp lệ.<br>3. Preview cập nhật từ state nháp; không gửi command, event nghiệp vụ hoặc metric.<br>4. `Lưu nháp` validate cấu trúc, ghi version mới và audit; menu khách đang thấy không đổi.<br>5. `Xuất bản` kiểm tra quyền, connection, capability, item và tất cả tham chiếu. Hệ thống tạo snapshot bất biến và sync connector.<br>6. Sync thành công: snapshot thành `PUBLISHED`, phát `default_menu.published`. Sync lỗi: giữ bản published cũ và cho phép retry cùng snapshot.<br>7. Runtime resolver nhận `customerId`: nếu FR-002 không trả assignment hợp lệ, trả Menu mặc định published; nếu chưa publish thì ẩn menu, không chặn chat.<br>8. Khi click, xác thực item thuộc published version, phát `menu.clicked` và `action.requested` một lần theo event ID. |
| Post-condition | Bản nháp được lưu hoặc bản mới được publish; runtime trả menu đúng phiên bản. |
| Luồng thay thế | - Đạt giới hạn: khóa `Thêm item`; API cũng từ chối request vượt giới hạn.<br>- Target action bị xóa/tắt: đánh dấu item lỗi và chặn publish; runtime click vào target hỏng ghi log, không chạy target khác.<br>- Xung đột version: không ghi đè; yêu cầu tải bản mới và merge.<br>- Kênh mất kết nối: vẫn cho lưu nháp, chặn publish.<br>- Không có thao tác xóa Menu mặc định. |
| Sub-flow | **SF-01 – Resolve menu:** FR-002 được hỏi trước; nếu không có assignment hợp lệ thì trả published Menu mặc định.<br>**SF-02 – Click item:** xác thực version/item, phát `menu.clicked` rồi `action.requested` với idempotency theo event ID.<br>**SF-03 – Retry sync:** dùng lại snapshot/request ID, không sinh version hoặc item trùng. |
| Giao diện hệ thống | Màn Menu mặc định gồm trạng thái draft/published/sync, danh sách item kéo thả, bộ đếm theo capability, popup cấu hình action, Mobile Preview, Lưu nháp, Xuất bản và Thử lại sync. |
| Yêu cầu phi chức năng | Preview phản hồi trong 100 ms trên thiết bị mục tiêu; API đọc p95 ≤ 500 ms, lưu nháp p95 ≤ 1,5 giây, không tính connector; publish có trace theo `requestId`; UI dùng được bằng bàn phím. |
| AC tương ứng | - **AC-AUT-001-01:** Kênh mới mở màn hình thấy một Menu mặc định rỗng và không có Xóa.<br>- **AC-AUT-001-02:** Lưu nháp hợp lệ không làm thay đổi menu khách đang thấy.<br>- **AC-AUT-001-03:** Publish hợp lệ tạo version mới, sync đúng kênh và ghi audit.<br>- **AC-AUT-001-04:** Sync lỗi vẫn giữ nguyên published version cũ; retry không tạo bản trùng.<br>- **AC-AUT-001-05:** Khách không có assignment nhận Menu mặc định; khách có assignment hợp lệ không nhận menu này.<br>- **AC-AUT-001-06:** Click item cùng `eventId` lặp lại chỉ phát một `action.requested`. |
| BR tương ứng | - **BR-AUT-001-01:** Mỗi kênh có đúng một Menu mặc định; không đổi loại, không xóa.<br>- **BR-AUT-001-02:** Item có thứ tự liên tục từ 1 và đúng một action.<br>- **BR-AUT-001-03:** Runtime chỉ dùng snapshot publish gần nhất đã sync thành công.<br>- **BR-AUT-001-04:** Assignment Menu tùy chỉnh hợp lệ luôn ưu tiên hơn Menu mặc định.<br>- **BR-AUT-001-05:** Retry publish phải idempotent; không sinh thêm version hoặc item. |
