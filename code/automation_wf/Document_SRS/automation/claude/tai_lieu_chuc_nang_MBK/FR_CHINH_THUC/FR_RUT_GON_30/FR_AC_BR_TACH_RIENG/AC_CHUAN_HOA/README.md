# AC chuẩn hóa — 1 AC/FR

Thư mục này là nguồn AC chính thức.

- Có đúng 30 file AC cho 30 FR.
- Mỗi file chỉ có một tiêu chí end-to-end.
- Mỗi tiêu chí có đúng bốn dòng Given, When, Then và And.
- Các trường hợp biên cùng một chức năng được viết chung trong tiêu chí để non-tech vẫn đọc liền mạch.
- DANH_MUC_AC_AUT.md là bảng tra FR – AC – BR.
- Thư mục ../AC/ là bản cũ, được giữ nguyên để đối chiếu.
