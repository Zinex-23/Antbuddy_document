# FR-AUT-008: Quy tắc

| Mục | Nội dung |
| --- | --- |
| Mô tả | Xây dựng automation theo mô hình KHI (trigger) – NẾU (condition) – THÌ (action). FR sở hữu cấu hình Rule, subscription event, đánh giá condition, thứ tự orchestration và execution log. Mỗi action được gọi qua command tới Owner; Rule không tự ghi menu, nhãn, field hoặc enrollment. |
| Đối tượng liên quan | Admin/Quản lý; Event Bus; các Action Owner |
| Pre-conditions | Người dùng có quyền; Event Bus và action catalog khả dụng; trigger/action target thuộc đúng tenant/kênh. |
| Điều kiện kích hoạt | Quản trị mở Quy tắc; hoặc Event Bus giao một event khớp trigger của Rule đang kích hoạt. |
| Luồng xử lý chính | 1. Danh sách có tìm kiếm, trạng thái, xem nhanh, Tạo/Sửa/Đổi tên/Nhân bản/Xóa/Bật-Tắt.<br>2. Builder yêu cầu ít nhất một trigger và một action. Nhiều trigger kết hợp OR; condition tree hỗ trợ group `ALL/ANY` có cấu trúc rõ ràng.<br>3. Trigger catalog khai báo event type và schema. Action catalog khai báo command, schema tham số, Owner và kiểu lỗi.<br>4. Quản trị sắp xếp action, chọn tần suất và chính sách lỗi `CONTINUE` hoặc `STOP`.<br>5. Lưu/publish kiểm tra schema, target, vòng tham chiếu tĩnh có thể phát hiện và quyền. Rule chưa hoàn tất không được bật.<br>**Runtime:** 1. Nhận event và khử trùng theo `(ruleId, eventId, publishedVersion)`.<br>2. Match trigger, tải snapshot khách hàng, đánh giá condition và tần suất. Không đạt thì ghi `SKIPPED` kèm reason.<br>3. Tạo Execution và gọi action theo thứ tự. Mỗi command mang `executionId`, `actionId`, `correlationId` và idempotency key.<br>4. Ghi riêng kết quả mỗi action; áp dụng chính sách lỗi đã cấu hình; kết thúc `SUCCEEDED/PARTIAL/FAILED`.<br>5. Event do action sinh ra giữ `correlationId` và `causationId`. Trong một chain, cùng rule không chạy lại cho cùng customer; chain bị ngắt khi vượt giới hạn độ sâu hệ thống. |
| Post-condition | Rule được lưu/kích hoạt; mỗi event có kết quả `SUCCEEDED`, `PARTIAL`, `FAILED` hoặc `SKIPPED` kèm execution log. |
| Luồng thay thế | - Target bị xóa/tắt: Rule tự tắt, `NEEDS_RECONFIGURATION`; event mới không chạy.<br>- Event schema không đúng: quarantine/DLQ và cảnh báo; không đoán giá trị.<br>- Action timeout: query Owner bằng idempotency key trước retry.<br>- Xóa/tắt Rule không hoàn tác action đã commit; execution đang chạy kiểm tra trạng thái trước action tiếp. |
| Sub-flow | **SF-01 – Condition tree:** trigger kết hợp OR; group điều kiện dùng `ALL/ANY` rõ ràng.<br>**SF-02 – Action:** chạy tuần tự qua command của Owner theo policy `CONTINUE/STOP`.<br>**SF-03 – Chống vòng lặp:** giữ correlation/causation ID, một Rule không chạy lại trong cùng chain/customer và chặn quá độ sâu.<br>**SF-04 – Tần suất:** mỗi event, once/customer/rule hoặc cooldown. |
| Giao diện hệ thống | Màn danh sách Rule có trạng thái/xem nhanh; builder KHI–NẾU–THÌ; trigger/condition/action cards; sắp xếp action; frequency/error policy; execution log và dialog impact. |
| Yêu cầu phi chức năng | Đánh giá trigger/condition nội bộ p95 ≤ 200 ms; delivery at-least-once kèm idempotency; log có thời hạn lưu; giấu dữ liệu nhạy cảm; metrics cảnh báo loop, DLQ, failure rate và latency. |
| AC tương ứng | - **AC-AUT-008-01:** Thiếu trigger/action/tham số bắt buộc thì không thể bật Rule.<br>- **AC-AUT-008-02:** Một trong nhiều trigger khớp và condition của nó đạt thì Rule chạy.<br>- **AC-AUT-008-03:** Action chạy đúng thứ tự; kết quả từng action hiển thị trong log.<br>- **AC-AUT-008-04:** Event giao lặp không tạo execution thứ hai.<br>- **AC-AUT-008-05:** Hai Rule kích hoạt chéo không tạo vòng lặp vô hạn.<br>- **AC-AUT-008-06:** Action cập nhật field được log là command tới FR-009, không ghi trực tiếp.<br>- **AC-AUT-008-07:** Tắt/xóa Rule không hoàn tác action đã hoàn tất. |
| BR tương ứng | - **BR-AUT-008-01:** Nhiều trigger là OR; logic condition tuân đúng cây `ALL/ANY`, không dùng precedence ngầm.<br>- **BR-AUT-008-02:** Action chạy tuần tự theo order; chính sách lỗi phải hiển thị trong UI.<br>- **BR-AUT-008-03:** `ONCE` tính theo customer + rule identity; sửa version không xóa lịch sử, bản sao có identity mới.<br>- **BR-AUT-008-04:** Một rule chỉ chạy một lần trong cùng causation chain/customer.<br>- **BR-AUT-008-05:** Rule chỉ orchestration; command phải qua public contract của Owner. |
