# FR-AUT-001: Menu chính (Persistent Menu)

| Mục | Nội dung |
|---|---|
| **Mô tả** | Cung cấp thanh menu điều hướng cố định nằm ở góc dưới khung chat (cạnh ô gõ tin nhắn):<br>- Mỗi fanpage có đúng **1 Menu mặc định** (tất cả khách mới vào đều thấy, không được xóa).<br>- Có thể tạo thêm nhiều **Menu riêng (tùy chỉnh)** cho từng nhóm khách (ví dụ: Menu khách VIP, Menu khách đã mua).<br>- Mỗi menu chứa tối đa **20 nút bấm**.<br>- Nút bấm có tính năng "Đổi menu": khi khách bấm vào nút, khung chat của riêng khách đó sẽ đổi sang menu khác. |
| **Đối tượng liên quan** | Admin, Quản lý shop |
| **Pre-conditions** | Đã kết nối Fanpage / Zalo OA và đang hoạt động. |
| **Điều kiện kích hoạt** | Người dùng vào mục: Tự động hóa ➔ Menu chính. |
| **Luồng xử lý chính** | **1. Xem menu**: Hệ thống hiển thị Menu mặc định và danh sách Menu riêng.<br>**2. Chỉnh sửa menu**: Bấm nút "Sửa" ở menu muốn chỉnh ➔ Danh sách nút hiển thị ra kèm bộ đếm (ví dụ: 3/20 mục).<br>**3. Thêm nút**: Bấm "Thêm mục menu" ➔ Nhập tên nút (≤ 30 ký tự) ➔ Chọn việc cần làm khi khách bấm (Gửi tin nhắn mới, Chạy kịch bản có sẵn, Mở website, hoặc Đăng ký nhận tin) ➔ Bấm Lưu.<br>**4. Đổi menu (nếu cần)**: Bật công tắc "Chuyển menu sau khi bấm" ➔ Chọn menu đích muốn đổi.<br>**5. Xuất bản**: Bấm nút "Xuất bản" ➔ Hệ thống đẩy menu mới lên Facebook/Zalo để khách hàng thấy ngay. |
| **Post-condition** | Menu được lưu vào hệ thống và hiển thị ngay trên khung chat Messenger/Zalo của khách hàng. |
| **Luồng thay thế** | - **AF-1 (Đủ 20 nút)**: Đã thêm đủ 20 nút ➔ Khóa nút thêm mới, báo: "Đã đạt tối đa 20 nút".<br>- **AF-2 (Không cho xóa Menu mặc định)**: Menu mặc định không có nút Xóa và không được đổi tên.<br>- **AF-3 (Xóa menu riêng đang có khách dùng)**: Bấm xóa ➔ Cảnh báo: "Có X khách đang dùng menu này". Khi xác nhận xóa, các khách đó sẽ tự động quay về thấy Menu mặc định.<br>- **AF-4 (Lỗi mạng khi xuất bản)**: Mất mạng hoặc token page hết hạn ➔ Bản nháp giữ nguyên không mất, hiện nút "Thử lại". |
| **Sub-flow** | - **SF-01 (Đổi menu cho riêng 1 người)**: Khách A bấm nút có cài đổi menu ➔ Hệ thống gọi API kênh đổi persistent menu cho riêng Khách A; khách khác mở chat vẫn thấy menu cũ.<br>- **SF-02 (Kéo thả đổi vị trí)**: Người dùng có thể kéo thả các nút lên xuống để đổi thứ tự hiển thị. |
| **Giao diện hệ thống** | - Màn hình danh sách menu: Cột menu mặc định, cột menu riêng, khung xem trước điện thoại (Preview) bên phải.<br>- Màn hình sửa menu: Ô sửa tên menu, danh sách nút kéo thả (counter n/20), nút Thêm nút, nút Lưu nháp, nút Xuất bản.<br>- Popup nút: Ô nhập tên nút (n/30 ký tự), danh sách chọn việc khi bấm, công tắc chuyển menu, nút Lưu. |
| **Yêu cầu phi chức năng** | - Xuất bản lên Facebook/Zalo trong ≤ 3 giây.<br>- Khung xem thử (Preview) cập nhật ngay khi gõ phím mà không cần tải lại trang. |
| **AC tương ứng** | - **AC-01**: Thêm đủ 20 nút ➔ Nút thêm bị mờ (disable), không cho bấm tiếp.<br>- **AC-02**: Để trống tên nút hoặc để trống link web ➔ Báo đỏ trường thiếu, không cho lưu popup.<br>- **AC-03**: Khách A bấm nút đổi menu ➔ Khung chat của khách A đổi menu mới thành công.<br>- **AC-04**: Xóa một menu riêng ➔ Khách đang dùng menu đó tự động thấy lại Menu mặc định. |
| **BR tương ứng** | - **BR-01**: Tối đa 20 nút/menu; tên nút tối đa 30 ký tự.<br>- **BR-02**: Menu mặc định là duy nhất cho mỗi trang, cấm xóa, cấm đổi tên.<br>- **BR-03**: Khách hàng chỉ thấy phiên bản menu đã xuất bản thành công gần nhất. |
