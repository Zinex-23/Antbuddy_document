# FR-AUT-009: Quản lý Mẫu Cấu hình & Nhân bản (Bản tinh gọn)

| Mục | Nội dung |
|---|---|
| **Mô tả** | Đóng gói và tái sử dụng cấu hình Automation cho nhiều trang/chi nhánh:<br>- **Thư viện mẫu hệ thống (System Templates)**: Cung cấp các gói kịch bản sẵn theo ngành nghề (Bán lẻ, Spa, Bất động sản, F&B...).<br>- **Tạo mẫu từ trang nguồn**: Đóng gói các Menu, FAQ, Kịch bản, Quy luật của một Page thành gói Template có phiên bản.<br>- **Áp dụng an toàn**: Khi áp dụng sang Page đích, toàn bộ cấu hình luôn ở trạng thái `DRAFT` / `INACTIVE` (không tự kích hoạt đè cấu hình đang chạy).<br>- **Kiểm tra phụ thuộc (Dependency Check)**: Tự động phát hiện và cảnh báo các thẻ tag, custom fields còn thiếu trên Page đích. |
| **Đối tượng liên quan** | Admin, Quản lý AntBot |
| **Pre-conditions** | Đã đăng nhập; có quyền trên Page nguồn và Page đích. |
| **Điều kiện kích hoạt** | Vào AntBot ➔ Mẫu cấu hình ➔ Tạo mẫu hoặc Áp dụng mẫu. |
| **Luồng xử lý chính** | **1. Tạo mẫu từ Page**: Chọn Page nguồn ➔ Đặt tên mẫu ➔ Chọn các thành phần cần đóng gói (Menu, FAQ, Sequence, Rule) ➔ Bấm Tạo mẫu (lưu bản snapshot phiên bản).<br>**2. Xem thư viện mẫu**: Duyệt danh sách mẫu cá nhân hoặc mẫu hệ thống ➔ Bấm "Xem trước nội dung" (xem cây luồng, số lượng bước).<br>**3. Áp dụng mẫu sang Page đích**: Chọn Page đích ➔ Hệ thống kiểm tra phụ thuộc (tag, custom field) ➔ Xác nhận áp dụng.<br>**4. Kiểm tra & Kích hoạt**: Mở Page đích kiểm tra các bản nháp vừa nạp ➔ Bấm "Xuất bản" khi đã sẵn sàng. |
| **Post-condition** | Cấu hình mới được ghi vào Page đích dưới dạng Bản nháp (`DRAFT`); Page nguồn giữ nguyên không đổi. |
| **Luồng thay thế** | - **AF-1 (Thiếu thẻ/trường phụ thuộc)**: Page đích chưa có thẻ `Khach_VIP` mà mẫu yêu cầu ➔ Hệ thống hiển thị tùy chọn: Tự động tạo thẻ mới trên Page đích hoặc Bỏ qua.<br>- **AF-2 (Trùng tên cấu hình trên Page đích)**: Menu hoặc Kịch bản đã có tên trùng ➔ Hệ thống tự động thêm đuôi `_ban_sao` để tránh ghi đè.<br>- **AF-3 (Page đích mất kết nối)**: Chặn thao tác áp dụng mẫu, thông báo kết nối lại trang. |
| **Sub-flow** | - **SF-01 (Kiểm tra Phụ thuộc Manifest)**: Quét toàn bộ ID thẻ, ID luồng, ID custom field được tham chiếu trong mẫu đối chiếu với Page đích.<br>- **SF-02 (Cơ chế Áp dụng An toàn)**: Toàn bộ công tắc "Kích hoạt" của Sequence và Rule khi nạp sang trang mới đều đặt mặc định = `OFF`. |
| **Giao diện hệ thống** | - **Màn Thư viện Mẫu**: Tab Mẫu hệ thống & Mẫu của tôi, bộ lọc theo ngành nghề, nút "Tạo mẫu mới", nút "Áp dụng".<br>- **Popup Wizard Tạo mẫu**: Bước 1: Chọn trang nguồn & thông tin mẫu; Bước 2: Chọn thành phần đóng gói (checkbox cây thư mục).<br>- **Popup Áp dụng mẫu**: Chọn trang đích, bảng kiểm tra phụ thuộc (Dependencies), nút "Xác nhận áp dụng". |
| **Yêu cầu phi chức năng** | - Thời gian đóng gói và áp dụng mẫu ≤ 5 giây cho gói 500 thành phần.<br>- Đảm bảo cô lập dữ liệu giữa các tổ chức (Tenant Isolation). |
| **AC tương ứng** | - **AC-01**: Áp dụng mẫu kịch bản sang Page B ➔ Kịch bản xuất hiện trên Page B ở trạng thái `INACTIVE`, không tự động gửi tin đến khách hàng của Page B.<br>- **AC-02**: Mẫu có tham chiếu tag `Hoi_Gia` chưa có trên Page B ➔ Hệ thống tự động tạo tag `Hoi_Gia` trên Page B.<br>- **AC-03**: Nhân bản cho 5 Fanpage chi nhánh ➔ Cả 5 fanpage đều nhận cấu hình đồng nhất. |
| **BR tương ứng** | - **BR-01**: Mẫu cấu hình không mang trạng thái `ACTIVE` / `PUBLISHED` sang trang đích.<br>- **BR-02**: Thao tác tạo mẫu không làm thay đổi cấu hình đang hoạt động của trang nguồn.<br>- **BR-03**: Chỉ tài khoản có quyền `ADMIN` mới được tạo và áp dụng mẫu. |
