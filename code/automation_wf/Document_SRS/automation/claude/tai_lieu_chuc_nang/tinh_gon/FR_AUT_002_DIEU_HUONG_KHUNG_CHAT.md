# FR-AUT-002: Điều hướng trên Khung chat (Bản tinh gọn)

| Mục | Nội dung |
|---|---|
| **Mô tả** | Cung cấp giao diện điều hướng cố định trên khung chat của kênh (Messenger, Zalo):<br>- **Menu chính (Persistent Menu)**: Gồm 1 Menu mặc định (cho mọi khách mới) và nhiều Menu tùy chỉnh (theo phân khúc khách). Mỗi menu ≤ 20 nút; hỗ trợ "Chuyển menu sau khi bấm".<br>- **Câu hỏi gợi ý (FAQ Chips)**: Tối đa 4 nút gợi ý xuất hiện khi mở chat. Gồm 1 hành động chính + các hành động bổ sung (gắn thẻ, cập nhật dữ liệu).<br>- Đồng bộ trực tiếp lên API kênh đối tác. |
| **Đối tượng liên quan** | Admin, Quản lý |
| **Pre-conditions** | Đã đăng nhập; Trang đang ở trạng thái kết nối (`CONNECTED`). |
| **Điều kiện kích hoạt** | Vào AntBot ➔ Tự động hóa ➔ Menu chính hoặc Câu hỏi thường gặp. |
| **Luồng xử lý chính** | **1. Cấu hình Menu chính**: Chọn menu (Mặc định hoặc Tùy chỉnh) ➔ Bấm "Chỉnh sửa" ➔ Thêm nút (≤ 20 nút, tiêu đề ≤ 30 ký tự) ➔ Chọn Action (Tạo tin, Chọn flow, Opt-in, Mở web) ➔ Bật/Tắt chuyển menu ➔ Bấm Lưu.<br>**2. Cấu hình Câu hỏi gợi ý (FAQ)**: Bấm "Thêm mới" (≤ 4 câu hỏi) ➔ Nhập câu hỏi (≤ 80 ký tự) ➔ Chọn Action chính ➔ Thêm Action bổ sung (nếu có) ➔ Bấm Lưu.<br>**3. Xuất bản**: Bấm "Xuất bản" ➔ Hệ thống gọi API kênh đồng bộ cấu hình mới lên khung chat khách hàng. |
| **Post-condition** | Cấu hình lưu vào DB; Menu và FAQ mới xuất hiện ngay trên khung chat của khách trên Messenger/Zalo. |
| **Luồng thay thế** | - **AF-1 (Đủ giới hạn)**: Đủ 20 nút Menu hoặc đủ 4 câu hỏi FAQ ➔ Vô hiệu hóa/ẩn nút thêm mới.<br>- **AF-2 (Xóa Menu đang dùng)**: Xóa Menu tùy chỉnh ➔ Khách đang dùng tự động về Menu mặc định; nút ở menu khác đang trỏ tới menu này tự động tắt chuyển menu.<br>- **AF-3 (Bảo vệ Menu mặc định)**: Không hiển thị nút Xóa hoặc Sửa tên Menu mặc định.<br>- **AF-4 (Trùng tên menu)**: Trùng tên trong cùng trang ➔ Chặn lưu, báo đỏ ô tên.<br>- **AF-5 (Lỗi đồng bộ kênh)**: Mất mạng/hết hạn token ➔ Bản nháp giữ nguyên, trạng thái `Đồng bộ thất bại` kèm nút "Thử lại".<br>- **AF-6 (Bấm FAQ)**: Khách bấm câu hỏi gợi ý ➔ Chạy action chính + phụ; tuyệt đối không kích hoạt từ khóa và không gửi tin mặc định. |
| **Sub-flow** | - **SF-01 (Chuyển menu sau khi bấm)**: Khách A bấm nút có chuyển menu ➔ Chỉ riêng khung chat của Khách A đổi sang Menu đích; khách khác vẫn giữ menu cũ.<br>- **SF-02 (Hành động bổ sung FAQ)**: Thực thi tuần tự ngay sau hành động chính (ví dụ: gửi báo giá ➔ tự động gắn thẻ `Quan_Tam_Bao_Gia`). |
| **Giao diện hệ thống** | - **Màn Menu chính**: Danh sách menu, thẻ Menu mặc định, nút "Tạo mới" menu tùy chỉnh, nút Chỉnh sửa, menu 3 chấm (Đổi tên, Nhân bản, Xóa), Mobile Preview.<br>- **Màn Chỉnh sửa Menu**: Danh sách mục (n/20), nút "Thêm mục menu", ô sửa tên menu, Mobile Preview.<br>- **Màn FAQ**: Danh sách 4 câu hỏi, nút Thêm mới, trạng thái xuất bản, Mobile Preview.<br>- **Popup nút**: Tiêu đề (≤ 30 ký tự), chọn Action, công tắc Chuyển menu, chọn Menu đích. |
| **Yêu cầu phi chức năng** | - Gọi API đồng bộ sang Meta/Zalo hoàn tất trong ≤ 3 giây.<br>- Dữ liệu cô lập 100% giữa các trang (`activePageId`). |
| **AC tương ứng** | - **AC-01**: Menu đủ 20 nút ➔ Nút thêm bị vô hiệu hóa.<br>- **AC-02**: Menu mặc định không có nút Xóa và không thể đổi tên.<br>- **AC-03**: Khách A bấm nút chuyển menu ➔ Chỉ khung chat Khách A đổi menu mới.<br>- **AC-04**: Thêm đủ 4 câu hỏi FAQ ➔ Nút Thêm mới tự động ẩn.<br>- **AC-05**: Khách bấm câu hỏi FAQ ➔ Bot gửi phản hồi, không chạy từ khóa, không gửi tin mặc định.<br>- **AC-06**: Xóa Menu tùy chỉnh ➔ Khách đang dùng tự động quay về Menu mặc định. |
| **BR tương ứng** | - **BR-01**: Menu chính ≤ 20 nút; tiêu đề nút ≤ 30 ký tự.<br>- **BR-02**: Mỗi trang có đúng 1 Menu mặc định (không được xóa, không đổi tên).<br>- **BR-03**: FAQ tối đa 4 câu hỏi; nội dung ≤ 80 ký tự, không trùng nhau trong trang.<br>- **BR-04**: Chuyển menu chỉ tác động đến khách vừa bấm nút.<br>- **BR-05**: Lượt bấm FAQ không kích hoạt Tin nhắn mặc định và không chạy Từ khóa. |
