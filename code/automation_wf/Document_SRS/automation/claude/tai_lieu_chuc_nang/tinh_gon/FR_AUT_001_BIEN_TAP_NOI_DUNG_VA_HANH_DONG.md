# FR-AUT-001: Bộ máy Biên tập Nội dung & Hành động (Bản tinh gọn)

| Mục | Nội dung |
|---|---|
| **Mô tả** | Cung cấp bộ công cụ dùng chung để biên tập tin nhắn và chuẩn hóa hành động:<br>- Soạn tin nhắn dạng đồ thị nhiều bước (Step Graph).<br>- Hỗ trợ khối nội dung: Text (≤ 640 ký tự, biến `{customer_name}`), Ảnh, Carousel (≤ 10 thẻ), Video, Audio, Template.<br>- Nút bấm (Button) & Trả lời nhanh (Quick Reply) ≤ 20 ký tự; gắn 1 hành động từ Action Catalog.<br>- Phân loại gửi: Trong 24h (`WITHIN_24H`) hoặc Ngoài 24h (`OUTSIDE_24H`).<br>- Quản lý trạng thái: Lưu nháp (`DRAFT`) ➔ Xuất bản (`PUBLISHED`). |
| **Đối tượng liên quan** | Admin, Quản lý |
| **Pre-conditions** | Đã đăng nhập tài khoản có quyền cấu hình; đã chọn trang (`activePageId`). |
| **Điều kiện kích hoạt** | Mở trình soạn thảo từ: FAQ, Tin mở đầu, Tin mặc định, Từ khóa, hoặc Kịch bản chăm sóc. |
| **Luồng xử lý chính** | **1. Thêm/Chọn bước**: Chọn bước hiện tại hoặc bấm "Tạo bước tiếp theo" (Tin nhắn hoặc Hành động).<br>**2. Soạn nội dung**: Chọn chính sách 24h; nhập Text (≤ 640 ký tự); thêm biến/emoji; thêm khối Ảnh/Carousel/Video.<br>**3. Gắn nút bấm**: Bấm "Thêm nút" ➔ Nhập tiêu đề (≤ 20 ký tự) ➔ Chọn 1 Action từ Catalog ➔ Nhập tham số ➔ Bấm Lưu.<br>**4. Nối bước**: Chọn "Bước tiếp theo" (hệ thống kiểm tra chống lặp vòng).<br>**5. Lưu & Xuất bản**: Bấm "Lưu" (ghi bản nháp) ➔ Bấm "Xuất bản" (tạo snapshot, gọi API kênh). |
| **Post-condition** | Bản ghi lưu vào DB. Khách hàng nhận đúng nội dung của bản snapshot xuất bản mới nhất. |
| **Luồng thay thế** | - **AF-1 (Vượt ký tự)**: Text > 640 hoặc Tiêu đề nút > 20 ➔ Chặn nhập, báo đỏ.<br>- **AF-2 (Đổi Action)**: Đổi Action A sang Action B ➔ Tự động xóa tham số của Action A, chỉ giữ Action B.<br>- **AF-3 (Lặp vòng)**: Nối bước tạo vòng lặp vô tận (A ➔ B ➔ A) ➔ Chặn lưu, báo lỗi chu trình.<br>- **AF-4 (Xung đột sửa đồng thời)**: Version gửi lên cũ hơn DB ➔ Báo lỗi `409 Conflict`, yêu cầu tải lại trang.<br>- **AF-5 (Lỗi mạng khi xuất bản)**: Gọi API kênh thất bại ➔ Giữ nguyên bản nháp, trạng thái `FAILED` kèm nút "Thử lại". |
| **Sub-flow** | - **SF-01 (Catalog 8 Action)**: `SEND_MESSAGE` (gửi tin tiếp), `FLOW` (chạy flow có sẵn), `OPEN_URL` (mở link web), `OPT_IN` (xin quyền nhận tin), `ADD_TAG` (gắn thẻ), `REMOVE_TAG` (gỡ thẻ), `UPDATE_CUSTOMER_FIELD` (lưu thuộc tính), `SWITCH_MENU` (đổi menu khách).<br>- **SF-02 (Quy tắc 24h)**: Nếu bước cấu hình `WITHIN_24H` nhưng khách đã ngoài 24h ➔ Tự động bỏ qua (Skip), không làm treo luồng. |
| **Giao diện hệ thống** | - Cột trái: Danh sách bước (`stepId`), nút thêm bước, kéo thả đổi thứ tự.<br>- Khung giữa: Chọn 24h, ô văn bản (bộ đếm n/640), danh sách nút bấm, nút thêm khối nội dung, chọn bước tiếp theo.<br>- Cột phải: Mobile Preview cập nhật theo thời gian thực.<br>- Thanh trên cùng: Tên luồng, nút "Xem thử", nút "Lưu" và "Xuất bản". |
| **Yêu cầu phi chức năng** | - Phản hồi Preview < 50ms.<br>- Không làm mất bản nháp khi rớt mạng lúc xuất bản. |
| **AC tương ứng** | - **AC-01**: Nhập Text đến 641 ký tự ➔ Chặn nhập, bộ đếm hiện `640/640`.<br>- **AC-02**: Nhập tiêu đề nút > 20 ký tự ➔ Chặn nhập.<br>- **AC-03**: Nối bước tạo vòng lặp vô tận ➔ Chặn lưu, báo lỗi.<br>- **AC-04**: Xuất bản lỗi mạng ➔ Bản nháp giữ nguyên 100%, hiện nút "Thử lại".<br>- **AC-05**: Thao tác trên Mobile Preview ➔ Không gửi tin thật, không sinh số liệu thống kê. |
| **BR tương ứng** | - **BR-01**: Text ≤ 640 ký tự; Tiêu đề nút/Quick reply ≤ 20 ký tự.<br>- **BR-02**: Tối đa 3 nút/khối; tối đa 11 Quick reply/bước; Carousel từ 1–10 thẻ (≤ 3 nút/thẻ).<br>- **BR-03**: Biến `{customer_name}` tự thay bằng tên khách; nếu thiếu dữ liệu thay bằng `""`.<br>- **BR-04**: Khách chỉ thấy phiên bản snapshot đã xuất bản thành công gần nhất. |
